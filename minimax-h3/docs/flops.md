# MiniMax-H3 Transformer 前向 / 反向计算量公式（以 S 为唯一变量）

## 模型常量（来自官方 config）

| 参数 | 值 |
|---|---|
| 层数 L | 50 |
| 隐藏维度 d | 5376 |
| 注意力头数 × 头维 | 56 × 128（注意力内维 D = 7168，注意 D ≠ d） |
| FFN 中间维度 F | 14336（普通两层 FFN，无门控） |
| 注意力结构 | MHA，融合 QKV 投影 + out_proj |

计数约定：1 MAC = 2 FLOPs；batch = 1；采用 FlashAttention（反向重算 QKᵀ/softmax）+ block 级激活重算；"attention 部分"仅指 S² 核心项（QKᵀ + Attn·V），QKV/out 投影与 MLP 统一归入"线性层"；不计 norm / RoPE / softmax 等逐元素开销及 AdaLN 分支。

## 通用形式

设序列长度为 S，则（FLOPs）：

| 阶段 | Attention 核心 | 线性层（attn 投影 + MLP） |
|---|---|---|
| 前向 | `4LDS²` | `L(8dD + 4dF)S` |
| 纯反向 | `10LDS²`（= 2.5 × 前向） | `2L(8dD+4dF)S`（= 2 × 前向） |
| 反向阶段（含重放） | `14LDS²`（= 3.5 × 前向） | `3L(8dD+4dF)S`（= 3 × 前向） |
| 完整迭代（前向+重放+反向） | `18LDS²`（= 4.5 × 前向） | `4L(8dD+4dF)S`（= 4 × 前向） |

系数来源：

- 线性层反向 = 2× 前向（每个 matmul 的反向含 dgrad + wgrad 两次同规模矩阵乘）
- FlashAttention 反向对 S² 项 = 2.5× 前向（因 P 矩阵不落盘，反向需重算一次 QKᵀ + softmax，再做 4 个反向 matmul：dV = PᵀdO、dP = dOVᵀ、dQ = dS·K、dK = dSᵀQ）
- Block 级激活重算：反向阶段先重放一次前向（+1× 前向 FLOPs）

## 代入 H3 常量后（单位：FLOPs）

> 注：8dD = 4dF = 308,281,344（因为 2D = F = 14336），线性层每 token 每层中 attn 投影与 MLP 各占一半。

| 阶段 | Attention 核心 C_att(S) | 线性层 C_lin(S) |
|---|---|---|
| **前向** | **1.4336×10⁶ · S²** | **3.0828×10¹⁰ · S** |
| **纯反向** | **3.584×10⁶ · S²** | **6.1656×10¹⁰ · S** |
| **反向阶段（含重放）** | **5.0176×10⁶ · S²** | **9.2484×10¹⁰ · S** |
| **完整迭代** | **6.4512×10⁶ · S²** | **1.2331×10¹¹ · S** |

## 校验（S = 38000）

- 前向 attention = 1.4336×10⁶ × 38000² ≈ **2.070 PFLOPs**
- 前向线性层 = 3.0828×10¹⁰ × 38000 ≈ **1.171 PFLOPs**
- 完整迭代总计 ≈ **14.0 PFLOPs**（attention 核心 9.32 PFLOPs 占 67%，线性层 4.69 PFLOPs 占 33%）

与前序逐步计算结果一致 ✓

## 两个有用推论

1. **交叉点**：令前向两项相等，解得 S = d(2D + F)/D = **21504**。即 S > 约 21.5k 后 attention 核心超过线性层成为主要开销；S = 38000 时前者已是后者的 1.77 倍。
2. **增长阶**：attention 核心随 S 二次增长，线性层线性增长。S 每翻倍，完整迭代中 attention 部分 ×4、线性层部分 ×2。
