# MiniMax-H3 Transformer 前向 / 反向计算量公式（以 S 为唯一变量）

## 模型常量（来自官方 config 及权重张量形状核实）

| 参数 | 值 |
|---|---|
| 层数 L | 50 |
| 隐藏维度 d | 5376 |
| 注意力头数 × 头维 | 56 × 128（注意力内维 D = 7168，注意 D ≠ d） |
| FFN 中间维度 F | 14336，**门控 FFN**：fc1 输出 2F = 28672（gate + value 两支），fc2 为 F→d |
| 注意力结构 | MHA（qkv_proj [21504, 5376] = 3×7168，确认非 GQA），融合 QKV 投影 + out_proj |

### 参数构成核算（按权重分片元数据统计，总计 33.123B，与官方 33.1B 吻合）

| 模块 | 参数量 | 说明 |
|---|---|---|
| 50 层 block 的 attn + MLP | 19.27 B | 每层 385.4M = qkv 115.6M + out 38.5M + fc1 154.1M + fc2 77.1M |
| AdaLN 分支 | 13.04 B | 每层 adaln_proj [96768, 2688] ≈ 260M，推理可预计算缓存 |
| token_refiner（2 层） | 0.77 B | 仅处理文本 token |
| condition_proj / time_embedder / final_layer / patch 投影等 | ≈ 0.08 B | 文本投影、时间嵌入、输出头等 |

计数约定：1 MAC = 2 FLOPs；batch = 1；采用 FlashAttention（反向重算 QKᵀ/softmax）+ block 级激活重算；"attention 部分"仅指 S² 核心项（QKᵀ + Attn·V），QKV/out 投影与 MLP 统一归入"线性层"；不计 norm / RoPE / softmax 等逐元素开销及 AdaLN 分支。

## 通用形式

设序列长度为 S，则（FLOPs）：

| 阶段 | Attention 核心 | 线性层（attn 投影 + MLP） |
|---|---|---|
| 前向 | `4LDS²` | `L(8dD + 6dF)S` |
| 纯反向 | `10LDS²`（= 2.5 × 前向） | `2L(8dD+6dF)S`（= 2 × 前向） |
| 反向阶段（含重放） | `14LDS²`（= 3.5 × 前向） | `3L(8dD+6dF)S`（= 3 × 前向） |
| 完整迭代（前向+重放+反向） | `18LDS²`（= 4.5 × 前向） | `4L(8dD+6dF)S`（= 4 × 前向） |

系数来源：

- 线性层反向 = 2× 前向（每个 matmul 的反向含 dgrad + wgrad 两次同规模矩阵乘；门控 FFN 的 fc1/fc2 同理）
- FlashAttention 反向对 S² 项 = 2.5× 前向（因 P 矩阵不落盘，反向需重算一次 QKᵀ + softmax，再做 4 个反向 matmul：dV = PᵀdO、dP = dOVᵀ、dQ = dS·K、dK = dSᵀQ）
- Block 级激活重算：反向阶段先重放一次前向（+1× 前向 FLOPs）

## 代入 H3 常量后（单位：FLOPs）

> 线性层每 token 每层 = 8dD + 6dF = 308,281,344 + 462,422,016 = 770,703,360（attn 投影占 40%，MLP 占 60%）。

| 阶段 | Attention 核心 C_att(S) | 线性层 C_lin(S) |
|---|---|---|
| **前向** | **1.4336×10⁶ · S²** | **3.8535×10¹⁰ · S** |
| **纯反向** | **3.584×10⁶ · S²** | **7.7070×10¹⁰ · S** |
| **反向阶段（含重放）** | **5.0176×10⁶ · S²** | **1.1561×10¹¹ · S** |
| **完整迭代** | **6.4512×10⁶ · S²** | **1.5414×10¹¹ · S** |

## 校验（S = 38000）

- 前向 attention 核心 = 1.4336×10⁶ × 38000² ≈ **2.070 PFLOPs**
- 前向线性层 = 3.8535×10¹⁰ × 38000 ≈ **1.464 PFLOPs**
- 前向总计 ≈ **3.534 PFLOPs**
- 完整迭代总计 ≈ **15.17 PFLOPs**（attention 核心 9.32 PFLOPs 占 61%，线性层 5.86 PFLOPs 占 39%）

2PD 交叉验证：2 × 19.268×10⁹（blocks 线性权重）× 38000 = **1.464 PFLOPs**，与线性层逐项计算分毫不差——2PD 本质上只覆盖参数参与的矩阵乘，恰好等于"线性层"部分。

## 两个有用推论

1. **交叉点**：令前向两项相等，解得 S = d(2D + 1.5F)/D = **26880**。即 S > 约 26.9k 后 attention 核心超过线性层成为主要开销；S = 38000 时前者已是后者的 1.41 倍。
2. **增长阶**：attention 核心随 S 二次增长，线性层线性增长。S 每翻倍，完整迭代中 attention 部分 ×4、线性层部分 ×2。2PD 估算（只含线性项）在 S = 38000 时即使用全量 33.1B 也只有 2.52 PFLOPs，比真实前向低 29%，且缺口随 S² 扩大——长序列必须补上 `4LDS²` 项。
