# 瑟斯顿《论数学中的证明与进步》论证地图

**On Proof and Progress in Mathematics** — William P. Thurston, 1994（arXiv: math/9404236）
缘起：回应 Jaffe–Quinn《"理论数学"》（1993）提出的"推测 vs. 严格"一维框架与角色分工方案。

---

## 总纲（Thesis）

> **数学的产出不是定理，而是人类的理解。**
> What we are producing is human understanding.

衡量数学进步的标准，是"我们所做的能否让人们更清晰、更有效地理解和思考数学"——而非定义、定理、证明的产出计数。

---

## 第一节 · 数学家到底完成了什么？
*What is it that mathematicians accomplish?*

**论点**：正确的问法不是"如何证明定理"，而是"如何增进人类对数学的理解"。
**关键证据**：
- 四色定理的机器证明之争：争议不在真假，而在无人能"理解"证明 → 人们要的是理解，不只是真值。
- 打印前一万个素数的谬误：答案的堆积 ≠ 想要的东西。
- 数学的递归定义：数学是数学家所研究的；数学家是增进人类对数学之理解的人 → 数学是随人类思维演化的人类活动。
**立靶**：DTP 模型（定义—定理—证明）丢失了问题来源与心理/社会维度；JQ 的 DSTP（加"推测"模块）只是给旧坐标系打补丁。

## 第二节 · 人们是如何理解数学的？
*How do people understand mathematics?*

**论点**：理解是多元的、依赖多种心理机能的过程，形式化必然"蒸发风味"。
**关键证据**：
- 导数清单：同一概念有 7+ 种真实而多产的理解方式（无穷小/符号/逻辑/几何/速率/逼近/微观），ε–δ 只是其一。
- 著名的"第 37 条"（余切丛的拉格朗日截面）：清单永不终止；"一个人的清晰意象是另一个人的威吓"。
- 心智六机能：语言 / 视觉·空间·运动觉 / 逻辑演绎 / 直觉·联想·隐喻 / 刺激—反应 / 过程与时间——人脑是多模块松耦合系统，不是单 CPU。

## 第三节 · 数学理解是如何被传达的？
*How is mathematical understanding communicated?*

**论点**：理解靠宽带人际信道流动；论文是有损的单通道编码；子领域是理解的生态单元。
**关键证据**：
- 膨胀律：两分钟对话 ≈ 一小时报告 ≈ 二十页论文——因对话是多模态（手势/图/音效）+ 双向反馈。
- 烤面包机原理：论文难读是因为缺先备"使用经验"，不是写得差；"语言只对使用者才是活的"。
- 交流文化的失灵：研讨会头 5 分钟掉队枯坐 55 分钟；课堂靠双向降标准维持；前排两专家充当假想听众。
- 形式主义的演化优势：可记录性选择压力逐代接管活思想；解毒剂 = 新生代的重新发现 + 命名压缩（"群""流形"）。
**纲领**：投入远大于现在的精力去传达思维方式与心智基础设施，而不只是最新结果。

## 第四节 · 什么是证明？
*What is a proof?*

**论点**：证明的可靠性来自共同体的批判性思维（弱点嗅探），而非形式核查；文献支撑而非第一性。
**关键证据**：
- 伯克利见闻：民间知识（folklore）无文本出处却可追溯；也有发表但公认错误的定理。
- Wiles 案例：专家凭高层思想先于细节核查而相信证明。
- 计算机对照：程序能跑所需的形式正确性比数学证明标准高两个数量级；大尺度形式化的成本是簿记与兼容性的组合爆炸（结局：重写一切或"国际标准委员会"）。
- 基础比上层建筑更摇晃：选择公理是"体面的虚构"、集合论多重宇宙、Gödel 不完备。
- 预言（已应验）：交互式证明助手将成为数学家标准环境（Lean/Coq）；但人类可理解的证明永远最重要。

## 第五节 · 人们为什么做数学？
*What motivates people to do mathematics?*

**论点**："定理署名权"作为共同体通用货币，扭曲行为、抹杀集体投入与传播劳动。
**关键证据**：
- 动机三层：内在快乐（含重新发现、学习、新看法）→ 社会互动（赶时髦的代价）→ 经济地位（互相评判的闭环）。
- 足球比喻：只奖励射门者会毁掉球队；路径上的定理"注定被某人证明"，署名奖励的是时序而非创造。
- "得分者跃迁"：中游者证明重要定理后地位阶跃、产出飙升 → 高产相当程度由地位与网络位置社会建构。
- 结论：JQ 的"推测者/证明者"分工把错误的记账单位制度化。

## 第六节 · 一些个人经历（对照案例）
*Some personal experiences*

**论点**：两种传播策略，两种领域生态——署名权挤死领域；投资基础设施救活领域。
**关键证据**：
- **叶状结构（失败案例）**：分类定理等密集产出 + 令人生畏的文风 → 高进入壁垒 × 低署名机会 → "Thurston 正在杀死这个领域" → 领域大撤离（生态死亡，非智识枯竭）。
- **几何化（成功）**：逆三十年潮流提出猜想、证明 Haken 情形；1200 人邮寄名单的讲义、Bowdoin 1980"两分钟对一小时"实验证明"证明依赖听众"；刻意放缓定理发表、优先建设基础设施、让出署名空间 → 领域蓬勃，最终被 Perelman（2003）以 Ricci 流另起炉灶证明——印证"一般证明不会是把同一证明往前推"。
- 个人资产负债表：未最大化"署名"，但"激发了数学"（stimulating mathematics）。

## 核心概念速查

| 概念 | 含义 |
|---|---|
| DTP / DSTP 模型 | "定义—定理—证明"（JQ 加上"推测"模块）的数学进步观：被批判的靶子 |
| 人类理解（human understanding） | 数学真正的产出；全文度量衡 |
| 膨胀律（expansion factor） | 心智编码 → 公共语言的转码损耗；对话:报告:论文 ≈ 2分钟:1小时:20页 |
| 心智基础设施 | 理解的前提条件：分布在人脑网络中的概念、意象、思维方式 |
| 定理署名权（theorem-credits） | 共同体的通用货币；被批判为错误的记账单位 |
| 体面的虚构（polite fictions） | 数学家信奉但明知不牢的基础原则（如选择公理） |
| 民间知识（folklore） | 共同体公认但无书面出处的知识；文献非第一性的证据 |
| 弱点嗅探 vs 形式核查 | 人擅长前者、拙于后者（机器相反）→ 可靠性的真正来源 |
